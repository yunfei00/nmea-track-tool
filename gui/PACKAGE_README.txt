NMEA Track Tool
===============

This package contains the Windows desktop track viewer and editor.

Run:

  nmea-track-tool.exe

The sample_data folder includes small NMEA files that can be opened from
the app:

  sample_data\clean_track.nmea
  sample_data\anomaly_track.nmea
  sample_data\noisy_track.nmea

This is the GUI tool. The separate umt-to-nmea package contains the
command-line UMT to NMEA converter.
